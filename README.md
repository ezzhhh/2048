# Обод — порошковая покраска дисков

Сайт цеха по покраске дисков. Структура как у сервисов порошковой покраски: главная, услуги, цены с калькулятором диаметра, галерея финишей, отзывы, контакты и запись.

Страницы лежат в корне. После правок в `generate_site.py` пересоберите HTML:

```bash
python3 generate_site.py
python3 -m http.server 8080
```

Откройте `http://127.0.0.1:8080/`.
