## 1. Главная `/`

### Header
Логотип / название · меню · кнопка мессенджера

### Hero
- Заголовок: Рефрижераторные перевозки Москва — Дальний Восток
- Подзаголовок: Собственный автопарк 86 / 93 / 105 м³. Возим как исполнители.
- CTA: Рассчитать перевозку · Написать в мессенджер
- Фон: реф + склад (без поезда, без Кремля/Золотого моста)

### Полоса маршрута
Москва — Благовещенск — Хабаровск — Уссурийск — Владивосток — Москва

### Факты (вместо «надёжность / своевременность»)
1. Собственный транспорт  
2. Парк 86 / 93 / 105 м³  
3. Температурный режим  
4. Маршрут туда и обратно  
5. Сопровождение груза  

### Услуги (превью, 6 пунктов)
Ссылки на раздел «Услуги»

### Как работаем
Заявка → расчёт → согласование → погрузка → в пути → выдача

### Парк
Блок с кубатурами 86 / 93 / 105 м³ + фото (когда будут)

### Форма заявки (короткая)
Имя, телефон, маршрут, тип груза, комментарий

### Footer
Контакты, реквизиты, меню
