# Хладокомбинат «Щелковский» — сайт на Tilda

Сайт рефрижераторных перевозок Москва — Дальний Восток.  
Бюджет разработки: 120 000 ₽. Платформа: **Tilda**.

## Как устроена работа

Tilda **не синхронизируется с Git** как обычный код.  
В этом репозитории лежит всё, что можно подготовить заранее и перенести в Tilda вручную или через Zero Block.

| Где | Что |
|-----|-----|
| `content/` | Тексты всех блоков и страниц |
| `design/` | Цвета, шрифты, правила UI |
| `tilda/zero-blocks/` | HTML/CSS для вставки в Zero Block |
| `docs/` | Пошаговая сборка в Tilda |
| `assets/` | Картинки, логотип (когда появятся) |

## Что делает Максим / агент

1. Пишет структуру и тексты.
2. Готовит Zero Block (кастомные секции).
3. Даёт точный чеклист сборки в Tilda.
4. При доступе к Tilda (логин / приглашение редактора) — собирает страницы в редакторе.
