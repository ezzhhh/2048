# Дизайн-токены

По согласованию с клиентом.

## Цвета

| Роль | Значение | Использование |
|------|----------|---------------|
| Фон | `#FFFFFF` | Основной фон страниц |
| Синий глубокий | `#0B2A5B` | Заголовки, тёмные секции |
| Синий | `#1E4F9C` | Кнопки вторичные, иконки |
| Голубой | `#4BA3E3` | Градиенты, акценты |
| Градиент секции | `#0B2A5B` → `#1E6FBF` | Hero, плашки услуг |
| Серебро | `#C0C6CE` | Тонкие линии, обводки иконок |
| Чёрный контур | `#1A1A1A` | Текст, иконки outline |
| Красный акцент | `#E31C3D` | Только CTA («Написать», «Рассчитать») |
| Текст вторичный | `#5A6570` | Подписи, мелкий текст |

## Типографика (Tilda)

- Заголовки: **Manrope** или **Montserrat** Bold
- Текст: **Manrope** Regular / Medium
- Не использовать Inter / Arial как основной акцент

## UI-правила

1. Больше белого, синий — секциями, не на всю страницу сплошняком.
2. Красный только на главных кнопках (1–2 на экран).
3. Скругления карточек: 12–16px (не «пузыри»).
4. Иконки услуг — разные по смыслу груза, не одна и та же фура.
5. Первый экран = оффер + парк + 2 CTA. Не начинать с «Наши услуги».

## Акценты контента (обязательно)

- Собственный транспорт
- Парк: **86 м³ / 93 м³ / 105 м³**
- Маршрут: Москва — Благовещенск — Хабаровск — Уссурийск — Владивосток — Москва
- Рефрижераторы (не общий транспорт, не ж/д)
