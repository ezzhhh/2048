# Пошаговая сборка сайта на Tilda

Максимально просто. Делай по порядку.

---

## Шаг 0. Что такое Git здесь

**Git не заменяет Tilda.**  
В Git лежит «кухня»: тексты, цвета, HTML для Zero Block, чеклисты.  
Сам сайт живёт в кабинете Tilda.

Как работать вдвоём с агентом:
1. Агент готовит файлы в `khladokombinat/`
2. Ты (или агент с доступом) переносишь блоки в Tilda
3. Правки текстов можно снова править в Git, потом обновлять Zero Block

Альтернативы «через Git» для Tilda:
- **Нет** полноценного `git push` → сайт
- **Да** Zero Block HTML из репо → вставить в Tilda
- **Да** экспорт сайта с Tilda (HTML) — но тогда это уже не Tilda-хостинг
- **Да** пригласить второго редактора в проект Tilda

---

## Шаг 1. Создать проект

1. Зайти на [tilda.cc](https://tilda.cc)
2. Создать новый проект: `Хладокомбинат Щелковский`
3. Настройки проекта → Цвета / Шрифты:
   - Фон `#FFFFFF`
   - Основной `#0B2A5B`
   - Акцент `#E31C3D`
   - Шрифт заголовков: Manrope или Montserrat
   - Шрифт текста: Manrope
4. Подключить домен позже (когда будет)

---

## Шаг 2. Создать страницы

Создать 4 страницы:

| Страница | URL (пример) |
|----------|----------------|
| Главная | `/` или `/home` |
| Услуги | `/services` |
| Online-заявка | `/request` |
| Контакты | `/contacts` |

В настройках каждой страницы: Title и Description из `content/texty.md`.

---

## Шаг 3. Шапка (меню)

Вариант А — стандартный блок Tilda **ME** / меню.  
Вариант Б — Zero Block из `tilda/zero-blocks/header.html`.

Состав:
- Слева: Хладокомбинат «Щелковский»
- Центр: Главная · Услуги · Online-заявка · Контакты
- Справа: красная кнопка → WhatsApp/Telegram (ссылку даст клиент)

Включить **фиксированную шапку** при скролле.

---

## Шаг 4. Главная — по блокам сверху вниз

Порядок блоков (см. `content/struktura.md`):

1. Header  
2. **Hero** — Zero Block `hero.html`  
3. **Маршрут** — Zero Block `route-bar.html`  
4. **Факты** — Zero Block или сетка Tilda (T123 / карточки)  
5. **Превью услуг** — иконки + текст  
6. **Как работаем** — 6 шагов  
7. **Парк** — 3 карточки 86 / 93 / 105  
8. **Форма** — стандартная форма Tilda (BF) → на email клиента  
9. Footer  

Тексты копировать из `content/texty.md`.  
Цвета — из `design/tokens.md`.

---

## Шаг 5. Страница «Услуги»

1. Плашка фактов сверху  
2. Сетка 8 карточек (Zero Block `services-grid.html` или 2 ряда по 4 карточки Tilda)  
3. Две кнопки: Рассчитать → `/request`, На главную → `/`

Карточки кликабельные: ведут на `/request` с пометкой типа груза (можно через `?cargo=`).

---

## Шаг 6. Online-заявка и Контакты

- Форма Tilda: все поля из `texty.md`
- Уведомления на email / Telegram (интеграция в настройках формы)
- Контакты: текст + кнопки мессенджеров + реквизиты

---

## Шаг 7. Мобильная версия

В Zero Block для каждого блока настроить **Mobile**:
- Hero: заголовок меньше, кнопки столбиком
- Сетка услуг: 1 колонка
- Маршрут: текст с переносами или горизонтальный скролл

Проверить iPhone + Android ширины в превью Tilda.

---

## Шаг 8. Перед сдачей

- [ ] Все ссылки меню работают
- [ ] Формы уходят на нужный email / мессенджер
- [ ] Кнопка «Написать» открывает WhatsApp/Telegram
- [ ] Нет поезда / Кремля / Золотого моста на баннере
- [ ] На главной видны 86 / 93 / 105 м³
- [ ] Favicon + Title страниц
- [ ] Метрика (если дали номер)
- [ ] Политика конфиденциальности (ссылка в форме)
- [ ] Опубликовать · проверить на телефоне клиента

---

## Шаг 9. Как ускорить работу с агентом

**Лучший вариант:** пригласить в Tilda редактором email агента/Максима → агент собирает блоки сам в браузере.

**Без доступа в Tilda:** агент отдаёт готовые Zero Block HTML → ты вставляешь:  
Zero Block → три точки → HTML/CSS/JS → вставить код из `tilda/zero-blocks/`.

Figma: если дашь **view-ссылку**, сверстаем ближе к макету по отступам и сетке.
