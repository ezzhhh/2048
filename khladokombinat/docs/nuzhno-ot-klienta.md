# Что нужно от клиента (чеклист)

Пока этого нет — сайт можно собрать на черновиках, но к публикации обязательно.

## Доступ

- [ ] Ссылка на **Figma** (view или edit)
- [ ] Доступ в **Tilda**: пригласить редактором на `project`  
  (Настройки проекта → Пользователи → Добавить email)
- [ ] Домен: есть / нужно купить / подключить к Tilda
- [ ] Куда слать заявки с форм: почта / WhatsApp / Telegram / CRM

## Контент и контакты

- [ ] Телефоны (Москва и/или ДВ)
- [ ] WhatsApp и Telegram для кнопки «Написать»
- [ ] Рабочий email для заявок
- [ ] Адреса офисов / стоянки
- [ ] Реквизиты для футера (ИНН, ОГРН, юр. адрес)
- [ ] Логотип (SVG или PNG на прозрачном фоне)
- [ ] Фото рефов / склада / погрузки (чем больше — тем лучше)
- [ ] Подтвердить список городов маршрута
- [ ] Подтвердить 8 типов грузов — все возите или что-то убрать
- [ ] Температурные режимы (диапазоны), если можно указать цифрами

## Не обязательно на старте

- [ ] Прайс (можно без цен, только форма)
- [ ] Политика конфиденциальности (текст)
- [ ] Яндекс.Метрика / счётчик (номер)
