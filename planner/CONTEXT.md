# Контекст для бота (снимок наших договорённостей)

Бот не читает чаты Cursor. Этот файл — выжимка. Обновлять, когда в чате с агентом меняется смысл задач.

## Фокус по умолчанию

ресторис

## Restoris / Место Топ

- Физика: воронка, Отказ / причины, оплата получена, доставка.
- Нужна таблица учёта упаковки: наличие / расход / остатки.
- Дальше: webhook Доставка (n8n или свой), деплой оплаты на form.mesto.top, электронные, активации, UniSender.
- Если человек пишет «таблица» без уточнения — почти всегда упаковка Restoris, не абстрактная таблица.

## VisaSmart

- Golden Visa, visasmart.ae. Не смешивать с Restoris.
- «визмарт» / «визсмарт» / vismart = визасмарт.
- Активно: рассылка по базе покупателей недвижимости (УТП 1–2 дня vs ~7 у конкурентов).

## Мобилог

- amo, воронка Заявки. Не смешивать с Restoris.

## Как принимать из Telegram

- Одно сообщение = сразу на доску. Не допрашивать.
- Фокус не менять, пока человек сам не напишет «фокус …».
- Неясный проект → «другое», не в Restoris.
- Следующим словом можно уточнить: визмарт / ресторис / мобилог / срок.
- «список» сначала показывает фокус, потом вне фокуса.
